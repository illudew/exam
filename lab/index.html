    高考物理模型模拟实验室 · 固定步长积分 + Canvas 2D · 仅用于教学演示，数值为理想模型结果

    ❔ 使用帮助

    • 选模型：左上「模型库」按 力学 / 电磁学 / 电路 / 实验 分类，或顶部搜索框输入关键词。
    • 调参数：右上「参数调节」拖动滑块或直接输入数值，画布与公式、数据即时更新（改变参数会重置演示）。
    • 播放：底部 播放 / 暂停 / 单步 / 重置，倍率支持 0.1×~4×，可切换 轨迹 / 矢量 / 网格 / 场线。
    • 视图：画布内按住拖动可平移，滚轮缩放，右侧 ＋ / － / ⤢ 复位。
    • 数据：右下「实时运动参量」显示 t、x、y、v、a、F、动量、动能、势能、机械能等，按模型追加专属量。
    • 教学：画布下方给出核心公式（KaTeX 渲染）、适用题型、解题思路、易错点与当前数值代入示例。
    • 主题、上次所选模型与各模型参数会自动保存在浏览器本地。
